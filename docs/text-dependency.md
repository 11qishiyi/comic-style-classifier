# 文字依赖性检验

## 问题

> "之前的训练集都已经去文字化处理了吗？该不会模型是根据文字判断画风的吧？"

这是个必须用实验回答的问题，因为漫画数据里三类文字的**书写系统截然不同**
（日文假名汉字 / 中文汉字 / 英文字母），模型完全可能偷懒去做「文字识别」而不是「画风识别」。

## 事实：训练数据没有做任何文字擦除

回看最初抽检的样本就知道：

- 日漫分格里有**日文对话气泡**（k_manga 来源）
- 欧美分格里有**英文旁白框和气泡**（COMICS 来源，黄金时代漫画旁白极多）
- ACN 封面上有**中文 / 日文标题**，部分还有越南文翻译标题
- k_classic 封面上有**英文标题和出版信息**

项目全程没有做过文字擦除或抹除。所以这个担心是有依据的，必须实测。

## 实验一：涂白消融

把检测到的文字区域**涂成纯白**，再重新推理，比较准确率变化。脚本：`scripts/10_text_ablation.py`。

| 数据集 | 类别 | 检测到的文字占比 | 原图准确率 | 涂白后 | 变化 |
|---|---|---|---|---|---|
| panel 测试集 | japanese | 1.9% | 0.9259 | 0.9259 | **+0.0 分** |
| panel 测试集 | western | 6.7% | 0.9770 | 0.9483 | −2.9 分 |
| panel 测试集 | **合计** | — | **0.9649** | **0.9430** | **−2.2 分** |
| cover 测试集 | chinese | 1.6% | 0.8254 | 0.8413 | +1.6 分 |
| cover 测试集 | japanese | 2.2% | 0.8413 | 0.8571 | +1.6 分 |
| cover 测试集 | western | 2.1% | 1.0000 | 1.0000 | +0.0 分 |
| cover 测试集 | **合计** | — | **0.8627** | **0.8758** | **+1.3 分** |

**结论**：擦掉文字后，分格模型仍有 **94.3%** 准确率，封面模型**不降反升**。
文字带来的信息量约 2 分，是次要线索，不是判断依据。

日漫分格侧零变化（0.9259 → 0.9259）尤其说明问题——模型完全不需要文字就能认出日漫。

## 实验二：三个自然实验（不依赖任何文字检测）

比涂白消融更有说服力，因为不涉及任何人工篡改：

| 实验 | 如果模型在读文字 | 实际观测 |
|---|---|---|
| Garfield 美国报纸连环画，**通篇英文** | 应判「欧美」 | **80% 判成「日漫」** |
| Manga109 **109 部日漫封面，日文标题** | 应判「日漫」 | **87% 判成「欧美」** |
| 《钢之炼金术师》100 张，**第三方已抹除全部文字** | 无从判断、准确率崩 | **100% 判对**，平均置信度 0.9947 |

前两行是「文字语言与预测方向**相反**」——如果模型靠文字，绝不可能出现这种结果。
第三行说明模型在**完全没有文字**的情况下依然稳定。

## 检测器的已知缺陷（必须说明）

第一版文字检测器**不可用**：它把眼睫毛、脸部贴网当成文字，
把 `panel/western` 的「文字占比」虚报成 **11.9%**，同时漏掉真正的对白框。
加入「文字必须位于大片白色区域内」这条判据后降到 **4.5%**，
说明原先那 11.9% 里有约 7.4 个百分点是网点误判。

即便如此，仍有以下残留误差，解读数据时要打折：

- **误报底线约 1.3%**：在已抹除文字的《钢炼》集上仍测得 1.3%，这是噪声地板
- **封面标题基本检不到**：封面标题多为彩底或压在画面上，不满足「白底黑字」判据，
  各类仅 1.6–2.2%。因此 cover 那 +1.3 分主要来自噪声清理，**参考价值有限**
- **粗体大字漏检**：如 "ANGRY AS WELL" 这类装饰性大字检不出
- 所以 panel 的 −2.2 分里，可能有一部分是「误删了画面」而非「删掉了文字」

不过 western 掉分、japanese 不掉分，这个不对称与两类的文字量差异一致
（western 检测到 6.7%，japanese 仅 1.9%），支持「文字是被用到了一点」的解释。

## 总结

| 问题 | 答案 |
|---|---|
| 训练集去文字化了吗？ | **没有**，三类文字俱全 |
| 模型靠文字判断吗？ | **不靠**。删掉文字后仍有 94.3%（panel）/ 87.6%（cover） |
| 文字有贡献吗？ | 有，但只是次要线索，约 2 分，且集中在欧美分格侧 |
| 最有力的证据 | 三个自然实验：文字语言与预测方向**相反**，模型完全没在读文字 |

**真正驱动预测的是画面本身**——这也和外部验证的结论一致：
模型失效的地方（Garfield、Manga109 复古封面）是因为**画风域不匹配**，
不是因为看不懂文字。

## 复现

```bash
# 统计各集合的文字面积占比
python scripts/10_text_ablation.py --coverage-only

# 可视化文字掩码（红色=判定为文字），人工核验检测质量
python scripts/10_text_ablation.py --dir datasets/comic_style/panel/test --debug 12

# 涂白消融
python scripts/10_text_ablation.py --model release/models/comic-style-panel-yolo11n-cls.onnx \
    --dir datasets/comic_style/panel/test --erase
python scripts/10_text_ablation.py --model release/models/comic-style-cover-yolo11n-cls.onnx \
    --dir datasets/comic_style/cover/test --erase
```
