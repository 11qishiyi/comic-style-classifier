# 已知限制

使用本数据集与模型前请先读这一节。这些限制多半由数据来源决定，无法通过调参解决。

## 1. 国漫没有内页数据

`chinese` 类全部是封面，因此 `panel/` 副集只能做「日 vs 欧美」二分类，不含国漫。
符合授权的现代中国漫画内页在公开渠道几乎不存在。

## 2. 中↔日是瓶颈，且受标注口径限制

cover 的错误几乎全部落在 chinese↔japanese 之间。但逐张核对错判样本后发现，
这是**标签定义问题而非模型能力问题**：ACN-Cover 按「作品来源国」标注，
而封面画风与来源国是交叉的（日本轻小说会用国漫风封面，中国网文会用日式动画风封面）。
详见 [experiments.md 第 4 节](experiments.md#4-错误分析中日混淆的本质是标签口径问题)。

**如果你的需求是「按画风分类」而不是「按来源国分类」，
本模型的中↔日边界不可直接采信。** western 类则几乎零错误（召回 1.000）。

## 3. `cover/` 三类素材的成像条件不统一

- 中日封面是 **190×247 缩略图**，欧美封面是 **474×640**，面积差约 5.8 倍
- 日漫封面偏黑白低饱和，国漫与欧美封面是全彩

模型可能部分依赖「清晰度」与「色彩」而非纯画风。
消融显示影响可控（训练充分后降采样只掉 2.0 分），但这是数据来源决定的，无法根除。

## 4. `western` 类内部时代不统一

`k_classic` 以 1950–1970 年代作品为主，COMICS 是 1938–1954 年黄金时代作品。
本数据集的「欧美系」实际偏向**经典欧美漫画**，与当代欧美漫画有差距。
若用于判别现代美漫，效果未知。

## 5. `panel/` 的日漫侧规模受限

日漫分格来自 311 页漫画，切出 531 格（过滤后）。
欧美侧已有 60 本书、1.8 万格，日漫侧补不上去——导致：

- `--max-ratio` 必须放宽到 3.0（否则日漫侧的 531 会限制整体规模）
- 交叉验证里日漫侧准确率（0.93）低于欧美侧（0.99）

要平衡两侧，需要更多授权的日漫内页来源。
可考虑申请 **Manga109-s**（87 卷日漫、含官方分镜框标注、可商用，需填表审批数天）。

## 6. 跨形态不可用

用 `panel` 模型判封面只有 0.822，用 `cover` 模型判分格只有 0.807。
请按输入形态选择对应模型：

| 输入 | 用哪个 |
|---|---|
| 封面、单幅插画 | `cover` / `comic-style-cover-yolo11n-cls` |
| 漫画单格（分格） | `panel` / `comic-style-panel-yolo11n-cls` |
| 整页漫画 | 两个都不适合，需先切分格或自行微调 |

## 7. 小尺寸输入置信度偏低

190×247 的缩略图需要放大到 224，与训练时的下采样路径不同，
置信度会偏低（但仍可用）。这是 PIL 与 torchvision 抗锯齿核差异的副作用，
详见 [troubleshooting.md 第 9 节](troubleshooting.md)。

## 8. 训练权重的法律地位

模型是从受版权保护的漫画图像上训练得到的。
训练权重的法律地位在多数法域尚无定论（美国几起相关诉讼未决）。
本项目仅作个人学习与交流用途，详见 [compliance.md](compliance.md)。
